What this proves
Each demo uses its existing declarative example and the same VideoLab compiler, bindings and renderer as the CLI. Every inspected frame comes from Snapshot.SceneAt. Parameterized demos compare frozen bindings; effect and data demos have one default binding. MP4 and WebM downloads are actual composed outputs, with repeat-render hashes verified before publication.


Limits and reproducibility
The composition demo lasts six seconds; focused examples last one second at 30 fps. Pause and inspect frames to study the changes. Source clips are generated color and tone fixtures. Exact repeated bytes are verified only with the same code, media, FFmpeg version and machine environment. This is experimental software, not a stable SoundScript API.


No local files are uploaded. The hosted page does not compile scripts or run FFmpeg. To compose your own assets, use the VideoLab CLI and documentation. Artifact checksums · Publication provenance
