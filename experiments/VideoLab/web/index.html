What this proves
The same compiled composition is bound to two parameter snapshots. Music gain and the animated shape’s starting position change; clip timing remains fixed. Every inspected frame comes from Snapshot.SceneAt, and both download formats come from the existing renderer.


Limits and reproducibility
Six seconds, 180 frames at 30 fps, 640 × 360. Source clips here are generated color and tone fixtures. Exact repeated bytes are verified only with the same code, media, FFmpeg version and machine environment. This is experimental software, not a stable SoundScript API.
