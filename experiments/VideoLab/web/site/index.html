A focused experiment
VideoLab is separate from the supported SoundScript NuGet package and CLI. This is a small programmable-composition Lab, not a nonlinear video editor.
Public mode offers verified sample combinations and frozen bindings. The optional local workbench uses the same native compiler and FFmpeg renderer for personal media and arbitrary supported parameter values. Exact repeated bytes require identical inputs, tools and machine environment.
