# Controlled caption font

DejaVu Sans, unmodified version 2.37, from the project's official release:
https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37

The accompanying LICENSE must travel with this font. Its SHA256 is
7DA195A74C55BEF988D0D48F9508BD5D849425C1770DBA5D7BFC6CE9ED848954.
The Lab embeds these bytes, checks the fingerprint when rendering and materializes
them in a generated temporary directory. No system font lookup or fallback occurs.
Phase 1 accepts single-line printable ASCII only. Text is clipped to its explicit
plane; alignment uses the pinned FFmpeg/FreeType glyph metrics. No wrapping,
font selection, shaping, runtime strings or cross-tool-version equality is promised.
